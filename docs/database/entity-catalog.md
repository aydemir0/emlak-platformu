# Entity catalog

## How to read this catalog

This catalog covers all 44 proposed entities and maps the exact 20 requested attributes across two compact matrices. `A` means **Assumption** (safe design default); `OD` means **Open Decision** (product/legal/operational choice). `SD` means soft delete, `HD` hard delete, `AI` append-only, `PII` personally identifiable information, and `RLS` row-level security. Column definitions are in [Schema draft](schema-draft.md), relationship rules in [Relationships](relationships.md), the conceptual model in [Domain model](domain-model.md), and diagrams in [ERD](erd.md).

`public_route_reservations` is the sole addition to the original 43-table set. It is required to enforce cross-table public-route uniqueness in PostgreSQL.

## Cross-cutting open decisions

- **Open Decision:** exact retention, erasure, legal-hold, and restore windows by data class.
- **Open Decision:** exact role/scope/RLS matrix and which tables, if any, are directly client-accessible rather than server-only.
- **Open Decision:** property asset-versus-listing identity, lifecycle vocabularies, appointment conflicts, contact deduplication, and customer merge reversal.
- **Open Decision:** SEO route taxonomy and whether a retired route may ever be reactivated for the same semantic owner. A route is never reassigned to a different owner.
- **Open Decision:** measured query patterns that justify optional search, reporting, spatial, or partial indexes beyond the required baseline.
